# Andy's Soulbound Graves 0.1.36

Current public release of Andy's Soulbound Graves for Minecraft Bedrock 26.30+.

- The held Soulbound Rune now uses its inventory icon in hand, so the item you see in inventory is the same art you see when holding it.
- Graves can form on soul sand, soul soil, and other solid ground. Placement uses Bedrock's own solid/air/liquid flags instead of a short hardcoded block list.
- Graves never replace bedrock, portals, spawners, budding amethyst, or blocks that already hold player property.
- World settings are available from the Behavior Pack gear icon in the world editor as well as the in-game operator form. The gear menu is applied only when those values change, so a live in-game change is not silently overwritten.
- Both linked packs include the branded pack icon.

No cheats, commands, experimental gameplay toggles, or extra dependencies are required. Existing graves and rune uses are preserved; import `Andys_Soulbound_Graves_0.1.36.mcaddon` and confirm both packs show version **0.1.36**.
